# Samples

This folder contains sample Bicep templates for common Workload Orchestration scenarios.

| Sample | Description                                                                                                                                     |
|---|-------------------------------------------------------------------------------------------------------------------------------------------------|
| [quickstart-basic](./quickstart-basic/) | Sets up Workload Orchestration to deploy solution on cluster. |
| [staging-solution](./staging-solution/) | Sets up Workload Orchestration with image staging.                                                                                            |
| [aio](./aio/) | Deploys Azure IoT Operations infrastructure to Arc-enabled Kubernetes clusters through Workload Orchestration. |
